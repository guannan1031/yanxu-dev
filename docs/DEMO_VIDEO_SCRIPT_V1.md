## 面试追问答法

**它会自动生成代码吗？**

会。`implement` 根据任务合同和显式允许的源码调用 Coding Agent，在隔离的 HEAD 归档中应用补丁并运行批准测试。输出是供人工审查的结果，不直接修改生产仓库。

**CI 在 merge 前还是 merge 后？**

两边都要。merge 前的 PR CI 验证候选改动；merge 后的 main CI 验证实际合并 commit、主分支组合和后续制品入口。研序记录两阶段证据，不把 PR 通过等同于生产交付完成。

**与 Superpowers 有什么区别？**

Superpowers 更偏 Agent 的开发方法与技能，帮助它计划、测试和调试。研序负责团队级权限、版本绑定、PR/CI、审计和试点验收，两者可以组合。

**商业价值是什么？**

开发团队已经有 Coding Agent，但仍需要控制修改范围、统一测试规则、核对最新 commit、记录失败返工并证明试点是否省时。研序可以以私有化部署、流程接入、规则配置、验收和持续支持收费。
