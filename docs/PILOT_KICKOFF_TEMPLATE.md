## 3. 交付规则

- [ ] 任务合同先于代码生成建立
- [ ] Policy 指纹已记录
- [ ] 生成只在隔离副本执行
- [ ] PR CI 在 merge 前通过
- [ ] main CI 在 merge 后通过
- [ ] merge、部署和付款保留人工决定
- [ ] 客户源码和密钥不进入公开仓库或截图

## 安全边界

这份模板应保存在客户批准的位置。公开 GitHub Issue 只填写范围和非敏感事实；详细仓库、内部 URL、成员信息、日志、源码、凭据和客户文件使用客户私有渠道传递。平台记录的是经批准的证据引用，不替代客户签字、付款或生产发布审批。
