# Upstream components

No upstream source is vendored in this repository.

| Component | Integration | Source and license |
|---|---|---|
| Codex CLI | Optional subprocess for structured AI diagnosis | https://github.com/openai/codex — Apache-2.0 |
| GitHub CLI | Read-only GitHub API and failed-log retrieval | https://github.com/cli/cli — MIT |
| actions/checkout | CI checkout; commit-pinned | https://github.com/actions/checkout — MIT |
| actions/setup-python | CI Python environment; commit-pinned | https://github.com/actions/setup-python — MIT |

Model access, account subscriptions and platform services have their own terms and costs. OpenHands SDK, gh-aw and Open SWE were researched as alternatives but are not installed dependencies or implemented integrations here.
